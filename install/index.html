Android install

Three taps to install

  1. 1
    Download the APK

    Tap Download for Android. If your browser asks, choose Download or Keep.

  2. 2
    Open the file

    Tap the finished download (or find CozyRoads.apk in your Files / Downloads app).

  3. 3
    Allow & install

    If Android says installs from this source are blocked, tap Settings, switch on Allow from this source, go back and press Install.

Android always asks you to confirm the install; a website can’t silently install an app. Prefer not to install anything? Play in your browser.
